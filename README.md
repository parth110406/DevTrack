# DevTrack 🚀

### Your Personal Productivity & Development Tracker

DevTrack is a personal productivity dashboard designed to help developers organize their technical growth, monitor problem-solving progress, manage projects, track technical skills, and keep internship and job applications organized — all in one place.

## ✨ Features

### 📊 Personal Dashboard
- Centralized productivity overview.
- Track projects, technical skills, and DSA progress.
- Animated statistics and progress indicators.
- Recent projects and activity overview.

### 💻 DSA Progress Tracker
- Track solved coding problems.
- Monitor progress across different DSA topics.
- View difficulty-wise problem-solving statistics.
- Visual progress bars and animated counters.

### 📁 Project Management
- Add and manage personal projects.
- Store project details and descriptions.
- Track project information and progress.
- View individual project details.

### 🧠 Technical Skills Tracker
- Add and manage technical skills.
- Track proficiency levels.
- Visualize skill development.

### 🎯 Application Tracker
- Organize internship and job applications.
- Track application information and status.

### ⚙️ Settings
- Customize dashboard preferences.
- Light and dark theme support.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

```bash
git clone https://github.com/parth110406/DevTrack.git
```

2. Navigate to the project directory:

```bash
cd DevTrack
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.
